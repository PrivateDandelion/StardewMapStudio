# Stardew Map Studio – Android

Touch-fähiger offline nutzbarer Karteneditor für Stardew Valley/SMAPI und TMX-Karten.

Diese APK enthält den Karteneditor v0.4 einschließlich zweigeteilter Tileset-Palette. Westhain- und Vanilla-Grafiken werden nicht als Spieldaten mitgeliefert. Eigene Mod-ZIP/TMX/Tileset-PNG können in der App geöffnet werden.

Unter **Actions** erzeugt der Workflow **Android debug APK** ein installierbares Debug-APK. Die Datei erscheint nach erfolgreichem Build unter **Artifacts**.

Quellcode aus der vorherigen Offline-HTML-Version, als Android-WebView-App verpackt.
